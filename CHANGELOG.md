## 0.0.1

* Initial OneUIX MVP release.
* Added design tokens: colors, typography, spacing, radius, elevation.
* Added theming primitives: `UixTheme`, `UixThemeMode`, `UixApp`, `UixConfig`.
* Added core components: button, text fields, card, list, badge, avatar, dialog, bottom sheet, snackbar, states, checkbox, radio, switch, dropdown.
* Added reusable patterns: login, OTP, search, filter, search+filter, profile, dashboard, settings, file upload, pagination.
* Added accessibility helper, responsive helper, localization placeholder, tests scaffold, and example app.
